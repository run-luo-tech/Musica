Musica Windows 便携版 · v0.2.0

1. 将整个压缩包解压到普通用户可写的文件夹，例如桌面或文档目录。
2. 双击 Musica.exe。无需安装 Python、pip、播放器或开发工具，无需管理员权限。
3. 曲库管理 → 批量导入 MP3；文件名为“歌手-歌曲名.mp3”。
4. 导出手机答案表（HTML），传到主持人手机后离线查编号。
5. 测试不记题；正式开始后跨轮去重；结束活动后返回测试。

适用目标：Windows 10/11 64 位。本机 Windows 11 已验证；其他电脑待现场验证。
首次启动会解包内置运行时，可能比后续打开稍慢；不要在 ZIP 内直接运行。
便携版在 EXE 旁生成 data 和 config；退出后复制整个 data 即可备份。
升级仅替换程序及说明，保留 data。项目内启动则共用项目根目录的既有 data。
发行包不包含音乐文件，歌曲需主持人自行导入。
