# 更新记录

## v0.3.1 — 2026-10-24

- 接入用户提供的 Musica Logo，主界面左上角常驻显示。
- Windows EXE、安装器、快捷方式和窗口采用品牌图标；Mac 同步应用图标。
- 图片资源内置，离开原图路径或离线运行仍可显示；升级保留数据。

## v0.3.0 — 2026-10-23

- 新增点击、拖动进度条定位；播放中继续播放，暂停时保持暂停。
- 支持播放前预选起点；方向键调整 5 秒，Home 回开头、End 到末尾附近。
- 重新播放从开头开始，切题清除起点；定位不揭晓答案、不增加正式题数。
- 新增统一 Windows 安装包，同一 Setup 支持首次安装和覆盖升级；后续升级沿用原安装位置，生成开始菜单入口。
- v0.2.0 便携版首次升级选择原 Musica.exe 所在目录，保留歌曲、编号、活动记录和配置；卸载保留用户数据。继续提供便携 ZIP。
- 更新使用说明书、截图、版本显示、项目启动器及构建流程。

## v0.2.0 — 2026-10-17

Windows 便携发行：MP3 曲库、永久编号、手机答案表、测试与正式活动、多轮去重、退出恢复。
