# v0.3.0 实施与发行

目标：支持点击/拖动定位播放；同一个 Windows 安装包支持首次安装、便携版覆盖升级与后续安装版升级。

职责与接口：Audio 负责绝对起播位置、暂停和播放时间偏移；Desktop 负责拖动预览、松开定位、尚未播放时的起播位置。Game/Store 继续仅在真实播放启动成功后记题，定位不增加题数。时长/定位输入为秒，position 输出毫秒。

数据与安装：保留 EXE 旁的 data/config/exports。安装器使用固定 AppId、当前用户权限和固定默认目录；后续升级沿用已登记目录。v0.2.0 首次升级选择包含 Musica.exe 的原文件夹，直接替换程序，无需搬迁数据库。安装包只列出程序、说明和许可文件，不写入用户数据；卸载也保留用户生成的数据。项目内启动器使用当期便携构建并复用根目录曲库。

交互：点击或拖动后松开提交定位；播放中继续播放，暂停中保持暂停；未播放时预选位置不记题；重新播放从零开始；切题/结束轮次清零；拖动时不被定时刷新覆盖。定位失败停止音频并给出中性提示，不显示答案或文件路径。

验收：原回归；真实静音 MP3 的前进/后退/暂停定位与位置偏移；UI 拖动及预选不记题、播放成功仅记一次、切题/重播重置；实际安装包新装、旧便携目录覆盖和重复安装时数据/配置保留、注册目录/快捷方式和实际 EXE 启动；新包不含个人数据。所有安装验证在隔离目录运行。

发布：源码提交与 v0.3.0 标签一致；GitHub Release 上传 Setup EXE 和便携 ZIP，说明便携版升级选原目录，保留 v0.2.0 历史版本。Mac 项目不属于本次更新。
